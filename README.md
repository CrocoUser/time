# TIME Project
<p dir="auto">A program for displaying time in the time zones of Europe and Russia. The code is written in Python using the time, os, and sys system modules (colorama has been added in the updated version)</p>
<h2 dir="auto"><strong>time.py OUTDATED</strong></h2>
<h2 dir="auto">Before launching, do:</h2>
<p dir="auto">pip install colorama</p>
<h2 dir="auto">Command Line Options:</h2>
<p dir="auto"><em>time-updated.py</em> - Standard mode. Show time in Europe and Russia</p>
<p dir="auto"><em>time-updated.py Europe</em> - Show only the time in Europe</p>
<p dir="auto"><em>time-updated.py Russia</em> - Show only the time in Russia</p>
